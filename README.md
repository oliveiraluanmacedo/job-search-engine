# Intelligent Job Search Engine

## Objective

Build an intelligent workflow that searches jobs using the JSearch API, filters irrelevant opportunities, evaluates qualified jobs with AI, and stores the results in Google Sheets.

This project is being developed incrementally, starting with a single data source (JSearch) before expanding to additional job boards.

## Tech Stack

- n8n
- JSearch API
- OpenAI
- Google Sheets
- JavaScript

## Current MVP

- Search jobs from JSearch
- Normalize job data
- Filter irrelevant jobs
- Remove duplicates
- Evaluate jobs with AI
- Save results to Google Sheets
